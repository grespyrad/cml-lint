## Why

Текущий форматтер склеивает свойства и вложенные выражения, не отделяет блоки и
расставляет лишние пробелы в generic types и ролях отношений. Нужен читаемый
канонический стиль для format и lint --fix без зависимости от JVM.

## What Changes

- Структурные переносы по AST, два пробела на уровень и пустая строка между блоками.
- Контекстные пробелы, свойства на отдельных строках, перенос длинных списков.
- Точные golden cases, corpus, dialect, CLI и fuzz regression tests.
- Закреплённые источники Java/Xtext formatter и воспроизводимый test-only oracle.

## Impact

Меняется canonical formatting; ранее отформатированные файлы могут потребовать
format -w. Синтаксис, токены, CLI flags и runtime-зависимости сохраняются.
